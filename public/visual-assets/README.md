## What is included

Original Akradhii-owned SVG assets only:

- `hero/` — cinematic desktop, tablet and mobile hero compositions.
- `agency/` — agency introduction visuals.
- `services/` — seven service icons and seven service illustrations.
- `backgrounds/` — abstract technology-themed dark backgrounds.
- `decorative/` — orange/gold glow, rings, particles and light effects.
- `portfolio/` — neutral portfolio layout templates, not fake client screenshots.
- `brand/` — logo mark, favicon source and brand social card source.

## Important

The portfolio section should use only real, client-approved project images. Do not publish `public/portfolio/*.svg` old violet/indigo sample placeholders as final case studies. Missing approved images are documented in `../../docs/visual-assets/missing-assets.md`.
